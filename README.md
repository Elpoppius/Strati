# Strati

Gestionale urbanistico-politico in sviluppo: governi una città europea verosimile attraverso i secoli, dai primi villaggi alla metropoli contemporanea. Ogni epoca costruisce sopra la precedente, e ciò che costruisci oggi diventa il vincolo di domani. Ispirazione centrale: lo sventramento di Parigi di Haussmann, riletto in chiave contemporanea.

Progetto di Fede, sviluppato con Claude. Motore: Godot 4.7.2.
